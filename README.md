# BYRMN

Build a premium, highly responsive dark-themed discography and portfolio web application for professional Audio Mixing Engineer RMN (byrmn.com) following the attached specification document and visual reference screenshots.

Key requirements from the spec:
- Aesthetics: Midnight-indigo and charcoal-slate dark colorway, electric blue accent (#0084FF), clean modern minimalist sans-serif with tracked monospaced metadata. No waveforms, consoles, or sci-fi gimmicks.
- Sidebar Rail: Fixed left navigation rail with the attached RMN graffiti logo, "BYRMN.COM" monospaced subtitle, vertical menu (CREDITS, ABOUT/GEAR, BOOKING) with a 2px electric blue active indicator line, social/streaming icons (Spotify, Apple Music, Instagram, Email), and "© 2026 RMN".
- Credits Matrix (Default View): Filter tabs ("Official Credits", "Original Releases", "Spec Mixes"), edge-to-edge square artwork matrix (including the attached RMN "Without You" artwork alongside realistic curated indie/alt releases), smooth hover overlay revealing Track Title and Artist Name.
- Detail Modal Card: Matching the attached reference screenshots, featuring large artwork, role pill badges, Artist/Track/Release year, Label/Studio/Roles metadata rows, tracklist with right-aligned blue 'M' mix credit badges, Apple Music / Spotify / Video buttons, and "More by [Artist]" thumbnail carousel.
- About / Gear View: Split layout with professional engineering bio, philosophy, and clean categorized gear & software inventory.
- Booking View: Structured quote request form for mixing leads with interactive electric blue focus states.
